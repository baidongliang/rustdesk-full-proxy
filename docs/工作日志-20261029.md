### 3. hbbs 防劫持死锁根因实锤（服务器日志 + 客户端证据闭环）

- **机制**：hbbs 防抢占对 **pk 与 IP 同时变化** 的 register_pk 一律回 `UUID_MISMATCH` 且不改库记录；
  盒子 `pm clear`（pk 变）+ 搬运到现场（IP 变）"双变"命中死锁；
- **后果**：库中地址停在已失效的旧出口 → punch 包转发进黑洞 → 盒子收不到 → 不回 PunchHoleSent →
  mac 端 18 秒静默超时；hbbs 认为记录"存在"故不回 OFFLINE，客户端无任何线索；
- **日志证据**：`ip/pk mismatch ... UUID_MISMATCH` 自 8-19 起累计 4193 条、峰值 ~30ms/条（无退避重连）；
- **对照**：DWDEV202503260023 同日三次换网只变 IP，全部自动放行——防劫持机制本身正常，"双变"才触发；
- **唯一性排查**：`ro.serialno = DWDEV202401090905` = ID 派生源，排除同 ID 双实例；
- **清理**（库已备份 `db_v2.sqlite3.bak-20261029`）：停 hbbs → 删 `peer` 死记录 → 重启 → 盒子 20s 内以新 IP+新 pk 重注册；
- **清理后验证**：mac → 盒子全链路成功，且为 **P2P 直连**（`Hole Punched = 10.10.14.116:38533` 真实局域网地址），
  登录、音频（48kHz）、VP8 视频 30fps 全部正常，零解码失败。

### 4. "能控制但画面不动"二次复发 → 定位为无障碍服务崩溃 → 实施运行时自愈

- **定位**：盒子 `input_service.log` 刷 `rustPointerInput dropped because InputService is not bound`；
  `dumpsys accessibility` 显示 `Crashed services: InputService`——无障碍服务运行中崩溃，Android 退避拒绝重绑；
  mac 侧输入指令全程畅通，只在最后一环被丢；
- **手工自愈**：按 `deploy_silent_perms.sh` 流程 adb 清退避标记（accessibility_enabled 0 → delete 键 → 恢复），服务重绑、控制恢复；
- **根因局限**：崩溃原因无可查记录（dropbox 无、日志无异常栈）；且 app 层自愈（SilentPermsHelper）只在启动/开机跑，
  运行中崩溃无人触发——用户确认后实施运行时自愈（见 §5）。

### 5. 无障碍运行时自愈实施 + 端到端验证

  Bound services 恢复、Crashed 清空。

### 6. register_pk 重连退避实施（盒子侧，Rust 注册层）

- **问题**：被持续 `UUID_MISMATCH` 拒绝时 `handle_uuid_mismatch` 无退避地 `update_id()` + 立即重发，
  形成 ~30ms 重连洪水，且设备 ID 反复翻转；
- **实施**：`src/rendezvous_mediator.rs` 4 处最小编辑——
  第 1 次不匹配保留"刷新 ID 立即重试"逃生通道；第 2 次起指数退避 1s→2s→…→60s 封顶
  （退避期内跳过 update_id 与重发），重试由周期性 register_peer（~12s）承担；注册 OK 清零预算；
  控制端会话链路（打洞/中继/输入）零改动。

## 二、环境问题修复备忘（Android 交叉编译链路，全部环境级、未改仓库）

| 问题 | 修复 |
|------|------|
| cargo-ndk `Failed loading manifest` | 必须在仓库根（Cargo.toml 所在目录）运行，`flutter/` 子目录不行 |
| bindgen `stdlib.h file not found`（kcp-sys） | `BINDGEN_EXTRA_CLANG_ARGS="--sysroot=$NDK/toolchains/llvm/prebuilt/darwin-x86_64/sysroot"`（用绝对路径，变量展开时序有坑） |
| `vpx/vp8.h not found`（scrap） | vcpkg android 树在 `~/vcpkg/installed/arm64-android`（不是 rustdesk-master 的 .toolchains 路径） |

完整可复用命令见文档《WRITE_SECURE_SETTINGS授权方案.md》第四节或本日志附录（下方环境变量块）：

```bash
cd <仓库根>
export ANDROID_NDK_HOME=/Users/dong/Library/Android/sdk/ndk/26.3.11579264
export VCPKG_ROOT=/Users/dong/vcpkg VCPKG_INSTALLED_ROOT=/Users/dong/vcpkg/installed
export BINDGEN_EXTRA_CLANG_ARGS="--sysroot=$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/darwin-x86_64/sysroot"
cargo ndk --platform 21 --target aarch64-linux-android build --locked --release --features flutter,hwcodec
cp target/aarch64-linux-android/release/liblibrustdesk.so flutter/android/app/src/main/jniLibs/arm64-v8a/librustdesk.so
llvm-strip flutter/android/app/src/main/jniLibs/arm64-v8a/librustdesk.so   # NDK 自带
flutter build apk --target-platform android-arm64 --release --obfuscate --split-debug-info ./split-debug-info
```
